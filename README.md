# Mediasorter

Разбирает домашний архив фото и видео: сам находит людей по лицам (без образцов), раскладывает фото по сюжетам
(море, горы, документы, чеки...), ищет по описанию («торт со свечами»), находит дубли и серии похожих кадров
и помогает быстро чистить архив. Всё работает **на твоём компьютере**, фото никуда не отправляются.

Удаление обратимо: Ctrl+Z (можно несколько раз подряд), а удалённые файлы ещё лежат в папке `data/_photosorter_deleted`.

## Установка за 3 шага

Нужен компьютер с Windows 10/11, macOS или Linux, ~10 ГБ свободного места. Видеокарта NVIDIA ускоряет разбор в разы,
но не обязательна.

**1. Поставь Docker**

- Windows и macOS: [Docker Desktop](https://www.docker.com/products/docker-desktop/), установить и запустить
  (дождаться надписи «Engine running»).
- Linux: [Docker Engine](https://docs.docker.com/engine/install/). Для видеокарты NVIDIA ещё
  [nvidia-container-toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html).

**2. Скачай Mediasorter**

Зелёная кнопка **Code → Download ZIP** вверху этой страницы, распакуй куда угодно (например, в `Документы`).

**3. Запусти**

| Система | Как запустить | Сменить папку с фото |
|---|---|---|
| Windows | двойной щелчок по **`start.bat`** | `change-folder.bat` |
| macOS | двойной щелчок по **`start.command`** (если Mac не даёт открыть: правый щелчок → «Открыть») | `change-folder.command` |
| Linux | в терминале в этой папке: `./start.sh` | `./start.sh --change` |

В первый раз откроется обычное окно выбора папки: выбери папку с фото и видео (подпапки тоже войдут).
Если в папке не нашлось ни одного фото, программа предупредит. Сетевую папку NAS можно выбрать прямо там
(Windows: «Сеть» или подключённый диск), тогда спросит логин и пароль от NAS.

Первый запуск идёт 10–30 минут: скачивается ~5 ГБ (программы и нейросети). Потом сам откроется браузер:
**http://localhost:8501**.

Фото разбираются в фоне: примерно час на 20 тысяч файлов с видеокартой (без неё в несколько раз дольше).
Обновляй страницу, люди и сюжеты появляются по мере разбора. Новые фото подхватываются сами раз в сутки.

## Фото на NAS (сетевом хранилище)

- **Windows:** в окне выбора папки выбери папку на NAS (раздел «Сеть» или подключённый диск, например `Z:`).
  Mediasorter сам спросит логин и пароль от NAS и будет подключаться к ней по SMB.
- **macOS:** подключи NAS в Finder («Переход → Подключение к серверу», `smb://адрес-NAS`) и выбери папку
  в окне выбора (она будет в `/Volumes/...`). После перезагрузки Mac NAS нужно подключать снова.
- **Linux:** подключи NAS в систему (например, строкой в `/etc/fstab`) и выбери папку из `/mnt/...`.
- **Вручную (любая система):** заполни в `.env` три строки, и Mediasorter сам подключит сетевую папку (SMB):
  ```
  NAS_SHARE=//192.168.1.10/photo
  NAS_USER=ivan
  NAS_PASSWORD=секрет
  ```
  `NAS_SHARE` — адрес NAS и имя общей папки, можно с подпапкой: `//192.168.1.10/home/Photos`.
  Пароль хранится только в `.env` на твоём компьютере (без запятых в пароле).
  После правки `.env` снова запусти `start.bat` / `start.command` / `./start.sh`.

## Как пользоваться

- **Люди** — все найденные люди. Подпиши знакомых (имя прямо на карточке), объедини, если один человек разбит на двух.
- **Поиск** — по описанию на русском или английском: «закат на море», «паспорт», «кошка на диване».
- **Стопки похожих** и **Копии** — оставить лучший кадр из серии / одну копию из дублей одной кнопкой.
- **Подборки** — собрать фото для кого-то: «Перемещать» (файл уезжает из архива) или «Копировать» (оригинал остаётся),
  переключатель слева. Готовую подборку можно упаковать в ZIP. Папки подборок — в `collections/`.
- Удаление: клавиша **Delete** или 🗑, без лишних вопросов. **Ctrl+Z** возвращает (несколько раз подряд — несколько шагов).

## Где что лежит

| Папка | Что там |
|---|---|
| `data/` | база (люди, имена, разметка) и удалённые файлы `data/_photosorter_deleted`. **Не удаляй**, если хочешь сохранить разметку |
| `collections/` | подборки |
| `.env` | твои настройки |

Окончательно освободить место после чистки — удалить папку `data/_photosorter_deleted` вручную.
Вернуть всё удалённое из консоли: `docker compose exec mediasorter python photosorter.py restore`.

## Частые вопросы

- **Остановить:** `docker compose down` в папке Mediasorter (или кнопка Stop в Docker Desktop). Запустить снова — `start.bat` / `start.command` / `./start.sh`.
- **Обновить:** скачай новый ZIP, перенеси в него свои `.env`, `data/` и `collections/`, запусти `start.bat` (`start.command`, `./start.sh`).
- **Что сейчас делает:** `docker compose logs -f` (или вкладка Logs в Docker Desktop).
- **Открыть с телефона / другого компьютера дома:** в `docker-compose.yml` замени `127.0.0.1:` на адрес этого
  компьютера в домашней сети, а в `PS_MEDIA_URL` — `localhost` на тот же адрес. Входа по паролю нет: **никогда не
  открывай эти порты в интернет** (проброс на роутере). Снаружи — только через VPN.
- **Порт 8501 занят:** поменяй `PORT=` в `.env`.
- **Не та папка:** `change-folder.bat` / `change-folder.command` / `./start.sh --change`. Чтобы начать
  с чистого листа, перед этим удали папку `data/`.
